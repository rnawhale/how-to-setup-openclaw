맥북에서 나만의 AI 비서팀 만들기

OpenClaw는 내 컴퓨터에서 직접 실행되는 개인 AI 비서입니다. 이 가이드는 코딩을 몰라도 따라 할 수 있도록, 설치부터 보안 설정, 아이메시지 연동, 여러 비서 만들기까지 순서대로 안내합니다.

OpenClaw가 뭔가요?

OpenClaw는 내 맥북 안에서 돌아가는 개인용 AI 비서 프로그램입니다. 클라우드 회사의 서버가 아니라 내 컴퓨터가 중심이 되고, 내가 이미 쓰고 있는 대화창(예: 아이메시지)으로 말을 걸면 됩니다. 하나의 비서만 두는 게 아니라, 목적별로 여러 비서(에이전트)를 만들어서 각자 다른 성격과 기억을 갖게 할 수 있습니다 — 예를 들어 사적인 일을 돕는 비서, 자료 조사를 담당하는 비서, 구직을 돕는 비서처럼요.

이미 ChatGPT 구독이 있다면 별도의 API 키나 결제 없이 로그인만으로 OpenClaw를 사용할 수 있습니다.

시작 전 준비물

  • macOS가 설치된 맥북 (최신 macOS 권장)
  • ChatGPT Plus 또는 Pro 구독 (API 키는 필요 없습니다)
  • 인터넷 연결
  • 아이메시지를 쓰려면, 해당 Apple ID로 메시지 앱에 로그인된 상태여야 합니다
  • 여유 시간 30~40분 (한 번만 설정하면 계속 사용 가능)

1 OpenClaw 앱 설치

터미널이나 개발자 권한 없이, 클릭만으로 설치할 수 있는 방법입니다.

  1. OpenClaw GitHub 릴리스 페이지에서 가장 최근 버전의 OpenClaw-*.dmg 파일을 내려받습니다.
  2. 내려받은 파일을 열어 OpenClaw.app을 Applications 폴더로 옮긴 뒤 실행합니다.
  3. 첫 실행 시 "로컬 게이트웨이 (이 맥에서 실행)"를 선택합니다. 앱이 자동으로 필요한 실행 환경을 설치합니다 — 별도 설치 프로그램이나 Homebrew는 필요 없습니다.
  4. 화면에 나오는 안내(대시보드 설정 마법사)를 따라 진행합니다. 메모리, 채널, 권한 설정은 이후 단계에서 하나씩 다룹니다.
맥이 화면·마이크·음성 인식·자동화·손쉬운 사용 권한을 요청하는 팝업을 띄울 수 있습니다. OpenClaw가 비서로서 화면을 읽거나 다른 앱을 조작하려면 필요한 권한이니, 각 팝업에서 허용을 눌러주세요. 나중에 시스템 설정 > 개인정보 보호 및 보안에서 언제든 취소할 수 있습니다.

2 ChatGPT 계정 연결하고 메인 모델 설정

API 키 없이, 갖고 있는 ChatGPT 구독으로 로그인합니다.

설정 마법사에서 OpenAI를 선택하고 "ChatGPT 계정으로 로그인"을 고르면, 브라우저 창이 열리고 평소처럼 ChatGPT 계정으로 로그인하게 됩니다. API 키를 발급받거나 결제 정보를 따로 입력할 필요가 없습니다.

터미널을 쓸 줄 안다면 아래 명령으로도 같은 작업을 할 수 있습니다:

openclaw onboard --auth-choice openai

메인 비서 모델: gpt-5.6-sol (low)

비서들의 "두뇌" 역할을 할 기본 모델은 OpenAI의 가장 성능이 좋은 gpt-5.6-sol로, 추론 강도는 low로 맞춥니다. 일상적인 비서 업무(일정 확인, 메일 요약, 간단한 조사)에는 충분히 똑똑하면서도 응답이 빠르고 비용 부담이 적습니다. 더 깊은 분석이 필요한 리서치 비서에는 5단계에서 추론 강도를 따로 올려줄 수 있습니다. 

openclaw config set agents.defaults.model.primary openai/gpt-5.6-sol
openclaw config set agents.defaults.model.reasoningEffort low
제대로 연결됐는지는 openclaw models list --provider openai로 확인할 수 있습니다.

3 게이트웨이 보안 설정 — 가장 중요한 단계

OpenClaw는 개인적이고 민감한 정보를 다루게 되므로, 이 단계는 절대 건너뛰지 마세요.

"게이트웨이"는 OpenClaw의 중앙 관제소입니다. 모든 비서, 모든 대화창(아이메시지 등)이 이 게이트웨이를 거쳐 연결됩니다. 게이트웨이가 안전하지 않으면 낯선 사람이 내 비서에게 말을 걸거나, 내 정보에 접근할 수도 있습니다.

다행히 기본값이 안전한 방향입니다. 최신 버전의 OpenClaw는 인증 없이는 아예 접속을 거부하며, 설정 마법사가 자동으로 비밀 토큰(암호)을 만들어줍니다. 아래 항목들은 "그 기본값을 절대 느슨하게 바꾸지 마세요"라는 체크리스트입니다.

꼭 지켜야 할 것

  • 게이트웨이는 내 컴퓨터에서만 접속 가능하게 둡니다. 설정값 gateway.bind가 loopback(기본값)인지 확인하세요. lan이나 인터넷 전체에 여는 설정으로 바꾸지 마세요.
  • 자동 생성된 토큰(비밀번호)을 안전하게 보관합니다. 필요하면 openclaw doctor --generate-gateway-token으로 새로 만들 수 있습니다. 이 토큰은 카카오톡이나 문자로 남에게 보내지 마세요.
  • 메시지 창은 "승인 후 대화(pairing)" 방식으로 둡니다. 아무나 먼저 말을 걸면 바로 대화가 시작되는 "open" 방식은 쓰지 마세요.
  • 다른 곳에서 원격으로 접속해야 한다면 게이트웨이를 인터넷에 직접 열지 말고, Tailscale 같은 개인 터널을 사용하세요. 이렇게 하면 게이트웨이는 계속 "내 컴퓨터 전용" 상태를 유지하면서 다른 내 기기에서만 접속할 수 있습니다.
  • 맥 자체를 디스크 암호화(FileVault)로 보호합니다. 비서의 대화 기록과 토큰이 저장되는 컴퓨터이기 때문입니다.
절대 하지 말아야 할 것 — 게이트웨이를 인증 없이 인터넷(0.0.0.0)에 직접 노출하는 것. 게이트웨이가 열려 있는 포트를 자동으로 스캔하는 공격자들이 실제로 존재합니다. "회사 밖에서도 쓰고 싶어서" 잠깐 열어두는 것도 위험합니다 — 항상 Tailscale 같은 사설 터널을 거치세요.

안전한 기본 설정 예시 (설치 마법사가 이미 이렇게 만들어줍니다):

{
  gateway: {
    bind: "loopback",
    auth: { mode: "token", token: "설치 시 자동 생성된 긴 문자열" }
  },
  channels: {
    imessage: { dmPolicy: "pairing" }
  }
}

4 대화창 연결하기 — 기본값: 아이메시지

이미 쓰고 있는 아이메시지 앱으로 비서에게 말을 걸 수 있게 설정합니다. 별도 앱 설치나 가입이 필요 없어 비기술 사용자에게 가장 편한 방법입니다.

준비물

  • 메시지(Messages) 앱에 내 Apple ID로 로그인되어 있어야 합니다.
  • OpenClaw가 메시지 기록을 읽고 보낼 수 있도록 전체 디스크 접근 권한과 자동화 권한을 허용해야 합니다 (팝업이 뜨면 허용을 누르면 됩니다).

설치 순서

  1. 아이메시지 연동 플러그인 설치: 
    openclaw plugins install @openclaw/imessage
  2. 맥의 메시지 앱과 대화할 수 있게 해주는 작은 프로그램(imsg) 설치: 
    brew install steipete/tap/imsg
    (Homebrew가 없다면 brew.sh의 안내를 따라 먼저 설치하세요.)
  3. 설정 파일에 아이메시지 채널을 추가합니다 ( user는 내 맥 사용자 이름으로 바꿔주세요): 
    {
  channels: {
    imessage: {
      enabled: true,
      cliPath: "/usr/local/bin/imsg",
      dbPath: "/Users/user/Library/Messages/chat.db",
      dmPolicy: "pairing"
    }
  }
}
  4. 게이트웨이를 시작(또는 재시작)합니다: 
    openclaw gateway
  5. 내 번호(또는 다른 가족 번호)에서 비서에게 처음 문자를 보내면 "승인 대기" 코드가 생깁니다. 아래 명령으로 승인해야 실제 대화가 시작됩니다: 
    openclaw pairing list imessage
openclaw pairing approve imessage <코드>
    승인 코드는 1시간 후 만료되니, 문자를 보낸 직후에 승인하세요.
고급 기능(읽음 표시, 답장, 반응 등)은 굳이 켜지 않는 것을 권장합니다. 이 기능을 쓰려면 macOS의 보안 기능(SIP)을 꺼야 하는데, 이는 맥 전체의 보안 수준을 낮추는 트레이드오프가 있습니다. 기본 기능(문자 보내기·받기)만으로도 비서 역할은 충분합니다.

5 목적별 비서팀 만들기

비서 한 명에게 모든 걸 맡기는 대신, 역할별로 나누면 훨씬 똑똑하게 일합니다. 각 비서는 서로 기억을 공유하지 않는 독립된 인격체입니다.

아래는 시작하기 좋은 4가지 비서 구성 예시입니다. 필요에 따라 이름과 역할은 자유롭게 바꿔도 됩니다.

개인 비서
personal
일정, 집안일, 가족 연락, 예약 등 사적인 일들을 처리합니다.
리서치 비서
research
궁금한 주제를 깊이 조사하고 요약해줍니다. 추론 강도를 더 높게 설정하면 좋습니다.
구직 도우미
job-hunter
채용 공고 정리, 이력서·자소서 다듬기, 회사 정보 조사를 돕습니다.
업계 동향 분석가
industry-watcher
관심 있는 업계의 뉴스와 트렌드를 정기적으로 훑어봅니다.

비서 만들기

각 비서마다 아래 명령을 한 번씩 실행합니다:

openclaw agents add personal
openclaw agents add research
openclaw agents add job-hunter
openclaw agents add industry-watcher

명령을 실행하면 비서마다 독립된 작업 공간(폴더)이 생기고, 그 안에 성격을 정의하는 SOUL.md(말투·성격), AGENTS.md(행동 규칙), USER.md(나에 대한 정보) 파일이 만들어집니다. 이 파일들을 열어서 각 비서의 말투나 우선순위를 자유롭게 적어두면, 그 비서는 매번 대화를 시작할 때 이 내용을 참고합니다. 예를 들어 리서치 비서의 SOUL.md에는 "정중하고 근거 중심으로 답한다", 개인 비서에는 "짧고 친근하게 답한다"처럼 적을 수 있습니다.

깊이 있는 조사가 필요한 리서치 비서와 업계 분석가는 추론 강도를 조금 높여줄 수 있습니다: 

openclaw config set agents.research.model.reasoningEffort medium
openclaw config set agents.industry-watcher.model.reasoningEffort medium

어느 문자를 보내면 어느 비서가 받을지 정하기

아이메시지에서 비서별로 별도의 번호를 쓰기는 어려우니, 가장 간단한 방법은 각 비서마다 그룹 채팅방을 하나씩 만들어 연결하는 것입니다. 설정 파일의 bindings 항목에서 어떤 대화방이 어떤 비서로 연결될지 지정합니다: 

{
  bindings: [
    { agentId: "personal", match: { channel: "imessage", accountId: "default" } }
  ]
}
비서를 더 추가하고 각각 다른 대화방에 연결하고 싶다면, OpenClaw 공식 문서의 멀티 에이전트 라우팅 페이지에서 자세한 예시를 확인하세요.

6 최종 보안 점검 — 기밀정보를 지키는 습관

비서가 개인적이거나 업무상 민감한 이야기를 다루게 되므로, 아래 습관을 들여두면 안심할 수 있습니다.

  • 비서에게 "이건 비밀이야"라고 말해도, 그 내용이 대화 기록(세션 로그)에 그대로 저장된다는 점을 기억하세요. 정말 민감한 정보는 애초에 입력하지 않는 것이 가장 안전합니다.
  • 주기적으로 openclaw security audit를 실행해 설정에 허점이 없는지 확인하세요.
  • 여러 사람이 함께 쓰는 컴퓨터라면, 그 컴퓨터에 OpenClaw를 설치하지 마세요 — 게이트웨이는 한 명의 개인 전용으로 설계되어 있습니다.
  • 사용을 잠시 멈추고 싶다면 openclaw gateway stop으로 언제든 끌 수 있습니다.
  • 토큰이 유출된 것 같다면 즉시 openclaw doctor --generate-gateway-token으로 새 토큰을 발급하세요.

문제가 생겼다면

비서가 응답하지 않아요

게이트웨이가 켜져 있는지, 채널 연결 상태가 정상인지 확인하세요:

openclaw gateway status
openclaw channels status --probe

아이메시지 승인 코드가 만료됐어요

다시 문자를 보내면 새 코드가 발급됩니다. openclaw pairing list imessage로 확인 후 1시간 안에 승인하세요.

ChatGPT 로그인이 풀렸어요

openclaw models auth login --provider openai
